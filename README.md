# 🔄 VLESS Collector

Бот, который каждый час собирает рабочие VPN-серверы из интернета и сохраняет их в файл.
Ты добавляешь ссылку на этот файл в своё VPN-приложение — и получаешь актуальный список серверов.

---

## Шаг 1 — Создать аккаунт на GitHub (если нет)

GitHub — это бесплатный сайт для хранения кода. Наш бот будет работать прямо там.

1. Открой **github.com** и нажми **Sign up**
2. Введи email, придумай пароль и имя пользователя (например `vasya123`)
3. Подтверди email — придёт письмо со ссылкой
4. Всё, аккаунт готов

---

## Шаг 2 — Загрузить проект на GitHub

1. Нажми кнопку **+** (правый верхний угол) → **New repository**
2. Заполни форму:
   - **Repository name:** `vless-collector` (именно так, без пробелов)
   - **Public** — оставь выбранным (бесплатные Actions работают только для публичных)
   - Остальное не трогай
3. Нажми зелёную кнопку **Create repository**
4. На следующей странице нажми ссылку **uploading an existing file**
5. Распакуй ZIP-архив на компьютере
6. Перетащи ВСЕ файлы и папки из распакованной папки в окно браузера
7. Внизу страницы нажми зелёную кнопку **Commit changes**

Готово — твой проект загружен!

---

## Шаг 3 — Указать своё имя пользователя

Открой файл **config.py** прямо на GitHub (кликни на него), нажми иконку карандаша ✏️ и измени строку:

```python
GITHUB_USERNAME = "YOUR_USERNAME"
```

на своё имя, например:

```python
GITHUB_USERNAME = "vasya123"
```

Нажми зелёную кнопку **Commit changes** → **Commit changes** ещё раз.

---

## Шаг 4 — Включить Actions (автозапуск)

1. Нажми вкладку **Actions** вверху страницы репозитория
2. Увидишь жёлтую плашку — нажми кнопку **I understand my workflows, enable them**
3. Слева появится **"Collect & Test VPN Configs"** — нажми на него
4. Нажми серую кнопку **Run workflow** → ещё раз **Run workflow**
5. Появится оранжевый кружок — бот запустился! Подожди 10–15 минут

После завершения в папке **output/** появятся файлы с серверами.

---

## Шаг 5 — Добавить подписку в VPN-приложение

После первого запуска твоя ссылка на подписку будет выглядеть так:

```
https://raw.githubusercontent.com/ТВОЁ_ИМЯ/vless-collector/main/output/VLESS_WORKING.txt
```

Замени `ТВОЁ_ИМЯ` на своё имя GitHub и добавь эту ссылку в Karing, Hiddify или v2rayN.

Дальше бот сам обновляет список каждый час — ничего делать не нужно.

---

## Шаг 6 — Яндекс Диск (необязательно)

Если хочешь, чтобы файлы дополнительно сохранялись на Яндекс Диск:

### Получить токен (3 минуты)

1. Открой в браузере: **https://yandex.ru/dev/disk/poligon/**
2. Нажми оранжевую кнопку **«Получить OAuth-токен»**
3. Войди в свой Яндекс-аккаунт
4. Скопируй токен — длинная строка вида `y0_AgAAAABx...`

### Добавить токен в GitHub (безопасно — никто не увидит)

1. В своём репозитории нажми **Settings** (вкладка вверху)
2. Слева найди **Secrets and variables** → **Actions**
3. Нажми зелёную кнопку **New repository secret**
4. В поле **Name** введи: `YANDEX_TOKEN`
5. В поле **Secret** вставь скопированный токен
6. Нажми **Add secret**

Всё! При следующем запуске бот автоматически загрузит файлы на Яндекс Диск в папку `/vless-collector`.

---

## Что делает каждый файл в output/

| Файл | Что внутри |
|---|---|
| `VLESS_WORKING.txt` | Все рабочие серверы — добавляй этот как основную подписку |
| `VLESS_ONLY.txt` | Только VLESS-серверы |
| `VMESS_ONLY.txt` | Только VMess-серверы |
| `TROJAN_ONLY.txt` | Только Trojan-серверы |
| `HYSTERIA_ONLY.txt` | Только Hysteria2-серверы (самые быстрые) |
| `TOP50.txt` | Топ-50 самых быстрых серверов |
| `index.html` | Страница со статистикой (открывается в браузере) |
| `stats.json` | Статистика в машиночитаемом формате |

---

## Как запустить вручную

Если хочешь запустить не дожидаясь автоматического запуска:

1. Вкладка **Actions** → **Collect & Test VPN Configs**
2. Кнопка **Run workflow** → **Run workflow**

---

## Запуск на своём компьютере

```bash
# Установить зависимости
pip install -r requirements.txt

# Полный запуск
python run.py

# Только скачать конфиги (без теста)
python run.py --sources

# Только протестировать (нужен предыдущий шаг)
python run.py --test

# Показать статистику
python run.py --stats
```
